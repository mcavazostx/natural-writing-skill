# Social and Canva-Style Production

Use when creating repeatable social graphics, branded templates, carousels, quote cards, infographics, thumbnails, or multi-format campaign assets.

## Goal
Achieve branded production speed without the obvious "template" look.

## Workflow
1. Start from brand rules, not from a template library.
2. Define the content hierarchy.
3. Create one strong master composition.
4. Build reusable constraints around typography, grid, image treatment, and CTA.
5. Adapt intentionally to each format.
6. Keep text editable and image areas replaceable.
7. Quality-check every resized version.

## Template-avoidance rules
- Do not use decorative shapes just to fill space.
- Avoid predictable headline-at-top/card-in-middle/logo-at-bottom layouts unless the content genuinely calls for it.
- Crop photos intentionally for each ratio.
- Do not let resize automation create awkward text wraps or tiny subjects.
- Keep brand elements consistent but vary composition enough to prevent feed monotony.

## Brand kit structure
Recommended reusable fields:
- Logo variants
- Primary/secondary fonts
- Display treatment
- Core palette
- Accent palette
- Background surfaces
- Photography rules
- Icon family
- Border/radius rules
- CTA styles
- Legal/footer treatment

## Batch production
For a content series:
- Lock grid and typography roles.
- Keep content fields variable.
- Define maximum headline lengths.
- Establish safe image crops.
- Create alternate composition patterns for long vs. short copy.
- Review outliers manually instead of forcing all content into one template.

## Social accessibility
- Maintain legible text sizes.
- Preserve strong foreground/background contrast.
- Do not place critical copy over noisy image regions without sufficient separation.
- Keep important content away from platform UI overlays/safe-zone edges.
