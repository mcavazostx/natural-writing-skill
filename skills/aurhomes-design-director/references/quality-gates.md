# Design Quality Gates

Apply only the sections relevant to the task.

## Universal
- [ ] Clear primary focal point
- [ ] One coherent concept
- [ ] Reading order is obvious
- [ ] Typography has intentional hierarchy
- [ ] Spacing follows a system
- [ ] Palette is controlled
- [ ] Imagery is specific and believable
- [ ] Effects are restrained
- [ ] No obvious generic-AI design tropes
- [ ] CTA is clear when one is needed
- [ ] Logo/branding does not overpower the message

## UI / Web
- [ ] Responsive across phone/tablet/desktop
- [ ] No horizontal overflow
- [ ] Semantic headings and controls
- [ ] Visible keyboard focus
- [ ] Accessible contrast
- [ ] Touch targets are comfortable
- [ ] Loading/error/empty states considered
- [ ] Reduced-motion behavior considered
- [ ] Images optimized and dimensions reserved
- [ ] One consistent icon family
- [ ] No arbitrary component-by-component color values

## Thumbnail / Ad
- [ ] Idea reads at small size
- [ ] Subject remains recognizable
- [ ] Text is short and legible
- [ ] No clutter around focal point
- [ ] Visual promise matches the actual content/offer
- [ ] CTA/value proposition is not buried

## Real Estate
- [ ] Property is not materially misrepresented
- [ ] Renovation concept matches stated budget/market tier
- [ ] Photography looks plausible
- [ ] Location/value proposition is clear when relevant
- [ ] Contact information is subordinate to main visual message

## Social / Canva
- [ ] Layout is not obviously template-derived
- [ ] Crop works for the exact platform ratio
- [ ] Text stays inside safe areas
- [ ] Brand system is consistent
- [ ] Series has enough variation to avoid monotony

## Final distinctiveness test
Ask: "If I removed the logo and business name, would this still feel intentionally designed for this exact message?"

If not, revise before delivery.
