# Source Notes and Provenance

This skill is an original synthesis. It does not reproduce the third-party skills verbatim. It incorporates high-level design principles and workflow ideas observed in the following public GitHub projects, then adapts them into one consolidated system.

## GitHub inspirations

### Frontend Design
Repository: https://github.com/am-will/codex-skills/tree/main/skills/frontend-design
Key ideas incorporated at a high level:
- Distinctive production-grade frontend design
- Strong typography and color direction
- Deliberate motion
- Avoidance of generic AI UI aesthetics

### World-Class Graphic Director
Repository: https://github.com/vibhuwolf/world-class-graphic-director
Key ideas incorporated at a high level:

- Distinctiveness over decoration
- Senior-level visual critique
- Campaign systems and image-prompt art direction

### Codex Design System
Repository: https://github.com/Bang-isme/CodexAI---Skills/tree/main/skills/codex-design-system

### Canva Craft Skill
Repository: https://github.com/social-media-skills/skills/tree/main/skills/canva
